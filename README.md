# operasional

Aplikasi Otomatisasi Laporan Operasional SPV & Income Sync 20 Outlets — PT Bahana Security Sistem (KC SulutGoTengPa).

## Tech Stack
- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Backend & Automation**: Node.js + Express + Playwright Chromium
- **Desktop Packaging**: Tauri v2 (`src-tauri/`)
- **CI/CD**: GitHub Actions (`.github/workflows/build-exe.yml`)
